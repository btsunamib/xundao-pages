# 寻道大千 · 单机修仙网页版

[直接游玩网页版](https://btsunamib.github.io/xundao-pages/)

一个直接运行在浏览器中的单机修仙游戏。使用独立绘制的 SVG 场景、人物和灵兽，以及独立设计的养成数值；适合 GitHub Pages 静态托管。

## 可以玩什么

- 砍树获取装备、积累修为；仙树 20 级、7 档品质，20 次低品质掉落保底上品。
- 8 个装备部位与连击、暴击、反击、吸血、闪避、击晕 6 种战斗词条。
- 自动砍树、按指定流派择优装备、分解低评分装备、80 格背包和装备分页。
- 10 个大境界，每个分初、中、后期，共 30 个阶段；通过雷劫提升境界。
- 180 个冒险关卡、100 层镇魔塔、本地 NPC 论道切磋。
- 7 种灵兽、灵兽升级与召唤保底，6 种精怪及升星、上阵位置。
- 四法修炼、3 种自动神通、10 个永久任务、每日任务与签到。
- 自动保存、本地存档导入/导出、最长 12 小时离线收益。
- 手机、平板、电脑布局；音效、动效、战斗速度可调。
- 首次联网加载后支持离线使用；可以添加到主屏幕。

这是用户选择的**全新单机存档版本**，使用本地进度，不接入官方账号和服务器。在线联机、妖盟、充值与官方限时活动不属于此版本。

## GitHub Pages 发布

1. 将本目录内的文件放在仓库根目录，确保 `index.html` 位于根目录。
2. 打开仓库 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/(root)**，然后保存。
5. 等待 GitHub Pages 部署完成，点击页面显示的网站地址。

所有资产均使用相对路径，不需要 Node.js、数据库、API 密钥或付费服务器。`.nojekyll` 禁用不必要的 Jekyll 构建。

## 本地运行

可以直接在浏览器打开 `index.html`；通过本地服务器运行时还可验证离线缓存：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。也可运行 `npm run serve`。

## 存档与操作

存档键是 `xundao-single-v1`，保存于网站对应浏览器的 `localStorage`。更换域名、设备或浏览器不会自动同步，请在设置中导出 JSON 存档再导入。导入前会显示道号、境界和进度，确认后替换本地进度；无效或不同版本文件会被拒绝。

每天按北京时间零点重置每日任务和仙礼。仙桃每 30 秒恢复 1 颗，同时获得灵石和修为；离线收益最多积累 12 小时。自动砍树只在页面可见且没有弹窗时运行，离线期间积累静修资源。

渡劫先消耗灵石，获胜后再扣除所需修为。失败或退出战斗保留修为。背包满时自动分解最早的装备；建议启用自动砍树或及时管理装备。

## 开发与验证

```bash
npm test
npm run package
```

测试使用 Node.js 自带测试框架，没有额外依赖。覆盖装备交换、资源不足、自动砍树、背包上限、战斗死亡顺序、重复结算防护、渡劫、任务奖励、召唤保底、每日重置、离线收益上限和存档校验。

`tools/package.py` 生成源码 ZIP，以及将 CSS、SVG 与 JavaScript 内嵌的单文件 HTML。无需网络即可打开单文件版本。

| 文件 | 用途 |
| --- | --- |
| `engine.js` | 独立游戏状态与战斗、掉落、养成、存档校验 |
| `app.js` | 五个玩法页面、弹窗、操作、自动保存 |
| `art.js` | 自绘矢量场景、人物、灵兽与图标 |
| `styles.css` | 响应布局与动效 |
| `sw.js` | 按部署路径隔离的离线缓存 |
| `tests/engine.test.cjs` | 核心玩法回归测试 |

## 更新离线缓存

修改前端文件后同步提高 `sw.js` 的缓存版本。部署新版本后刷新页面；存档键与文件格式保持兼容时，原有进度继续保留。
